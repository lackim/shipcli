# @shipcli/cli

The top-level command for the shipcli build and distribution toolkit.

```bash
npm install --global @shipcli/cli
shipcli --help
```

It can scaffold CLI projects, prepare npm releases, build Bun binaries, generate
Homebrew formulae and changelogs, and create a Next.js landing page.

shipcli is currently in early access. Review a release with
`shipcli publish --dry-run` before publishing. See the
[shipcli repository](https://github.com/lackim/shipcli) for full documentation.
