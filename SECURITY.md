# Security policy

## Supported versions

shipcli is currently in early access. Security fixes are applied to the latest
published `0.x` release only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository:

<https://github.com/lackim/shipcli/security/advisories/new>

Include the affected package and version, reproduction steps, impact, and any
suggested mitigation. You should receive an acknowledgement within seven days.
Please allow time for a fix before public disclosure.
